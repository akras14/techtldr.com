The PHP security team announced a security release for Wednesday, 21 October 2026 at 14:00 UTC. It addresses two critical vulnerabilities, each rated CVSS v4.0 9.2.

- The notice does not say which versions are affected or what the bugs are. Full details and fixed versions will be published with the release.
- The team asks all PHP users to prepare now so they can upgrade as soon as the release is out.
- It may release earlier if details of either vulnerability become public or if active exploitation appears in the wild.
