**Bottom line:** MicroZig, the Zig embedded project, now forbids LLM use of any kind in its GitHub organization and Discord server. The rule takes effect October 28, 2026 and is adapted from Zig's own Code of Conduct.

**What is banned**
- LLM-generated content, whether code or prose, and paraphrasing LLM output.
- LLMs for editing, including spelling and grammar fixes.
- LLMs for translation. Posting in your native language is welcome, and readers can use their own translation tools.
- LLMs for brainstorming and then sharing the results, including advice from a chatbot used to draft an issue comment.
- LLMs for finding bugs.
- Talking about use of chatbot or LLM services.

The rest of the document keeps the usual strict conduct rules: on-topic technical discussion only, and no discussing the Code of Conduct itself in project spaces. Violators are removed.
