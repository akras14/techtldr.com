**Bottom line:** a single X post claims Claude Code now carries a rule, pushed from Anthropic's servers, against building recreations of specific existing games. Treat it as an unconfirmed report.

The post says the rule appeared around Oct 27 under a flag named "tengu_heron_brook", with no setting to disable it. It quotes the rule as: "Do build original games, games in a genre, and games from the user's own designs and assets. Don't build a recreation of a specific existing game, even if it is renamed or called original."

- **What it covers (as quoted):** original games, genre games and games from the user's own assets are fine; one-to-one recreations are not, even if renamed.
- **Why it matters:** because it's delivered by a server-side flag, behavior can change without a client update, and users can't opt out.
- **What's missing:** the post gives only a screenshot as evidence and no statement from Anthropic. It also asks, without answering, whether this ends game rewrites and modding. The quoted wording targets recreations, not mods.
