**Bottom line:** Claude Duet moves Claude from a chat you start to an agent that runs continuously. You hand it work by message (text or voice) in a single persistent thread, and it works on a cloud computer using connected apps. It sends a morning brief, drafts next steps, and then stays quiet until something needs you.

- **What it does:** takes on small and large tasks, such as scheduling meetings, rebuilding a deck, or building a dashboard that refreshes daily, and returns finished docs, sheets or decks for review.
- **Approvals:** it asks before sensitive operations like sending messages or paying. Approvals, logins and safety checks run in the agent's own cloud computer, and you can see what it has done and steer it.
- **Carries over:** your Claude memory, skills and apps; the page cites more than 6,000 connectors and plugins.
- **Availability:** research preview, Pro and Max plans in the US, waitlist. Powered by Opus 5.5.

The page is product marketing with mock scenarios, so there is no detail yet on pricing, limits or how reliably it decides what is worth interrupting you for.
